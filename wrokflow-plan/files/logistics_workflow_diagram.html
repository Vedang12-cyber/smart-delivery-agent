Routing Algorithm

// Haversine distance formula
Speed: high-priority first
        → nearest-neighbor

Cost: nearest-neighbor
        all orders by dist

Balanced: score = dist(70%)
        - priority(30%)

Emergency: new order first
        → optimize rest

Risk Factors Checked

CRITICAL: fuel < 15%
LOW FUEL: fuel < 30%
MODERATE: fuel < 50%
            + dist > 150km

LONG ROUTE: dist > 200km
SLA BREACH: Cost Mode
              + high priority
DELAY RISK: low orders
              in Speed/Emergency
