# Smart Delivery Optimization Agent

## Problem
Traditional routing systems only optimize distance and ignore operational strategy.

## Solution
An agentic logistics system that selects strategy modes, optimizes routes, evaluates risks, and dynamically replans.

## Features
- Strategy Mode Selection (Speed / Cost / Balanced / Emergency)
- Priority‑aware routing
- Risk analysis
- Explainable decisions
- Dynamic replanning

## Tech Stack
n8n, LLM API, JavaScript, Webhooks, JSON

## Architecture
Input → Strategy Selection → Route Optimization → Risk Analysis → Response

## How to Run
1. Import n8n workflow JSON
2. Add API key
3. Run webhook
4. Send test JSON
